Este repositorio contiene el desarrollo de un modelo de regresión predictiva para estimar el Ingreso Mensual Recurrente (MRR) del próximo trimestre en una empresa SaaS B2B. El proyecto destaca por la construcción de una arquitectura robusta utilizando Pipelines de Scikit-Learn y transformadores personalizados (Winsorizer, FeatureEngineering) para automatizar la limpieza de datos y garantizar cero fuga de datos (data leakage). El análisis culmina con la extracción de la importancia de variables (Feature Importances) para traducir los resultados matemáticos (R², MAE) en acciones estratégicas de retención para el equipo de Customer Success.
